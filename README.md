# 課題 6-2: パッケージの利用

### 課題の説明
`logic`パッケージを作成し、課題6-1で作成した`Calculator`クラスをそのパッケージに所属させなさい。
その上で、別パッケージ（またはデフォルトパッケージ）に作成する `Prog62` クラスの main メソッドから呼び出し、同様の実行結果が得られるようにコードを書き換えること。

※ なお、`src/main/java` に課題内容に沿ったフォルダ構造の雛形を用意してある。

#### 注意点
別パッケージから `Calculator` クラスやそのメソッド（`time`, `divide`）を呼び出すには、適切なアクセス修飾子（`public`）を指定する必要がある点に注意すること。
